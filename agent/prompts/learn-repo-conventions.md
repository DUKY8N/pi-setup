이 저장소의 코딩 스타일과 기여 관례를 학습해줘.

분석 범위:
$ARGUMENTS

범위가 비어 있으면 저장소 전체를 대상으로 하되, 우선순위는 다음과 같이 둬:
1. CONTRIBUTING 문서
2. README와 개발 관련 문서
3. lint 설정
4. formatter 설정
5. 테스트 설정
6. 기존 소스 코드
7. 최근 커밋 또는 최근 변경 패턴
8. 패키지/의존성 설정 파일

작업 지침:
1. 기존 코드, lint 설정, formatter 설정, CONTRIBUTING 문서, 테스트, 최근 패턴을 확인해.
2. 아래 항목별 관례를 추출해:
   - 네이밍
   - 에러 처리
   - 로깅
   - API 설계
   - 파일 구성
   - 테스트 스타일
   - 의존성 사용 방식
3. 코드베이스 안에서 실제 예시를 찾아 함께 설명해.
4. 파일은 절대 수정하지 마.
5. 확실한 규칙과 추론한 관례를 구분해.
6. 근거가 약한 내용은 단정하지 말고 “추정”으로 표시해.
