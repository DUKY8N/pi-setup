---
description: 방금 변경한 작업을 다시 검토해 품질을 확인하고 실수를 수정
---

방금 완료한 작업을 한 번 더 살펴보고 문제를 찾아 수정한다. 다음 항목을 비판적인 관점에서 검토한다.

- 구현의 정확성과 완전성
- 코드의 견고성
- 새 함수를 만들기보다 기존 코드 재사용 및 중복 방지
- 오류 관리와 처리
- 잠재적 버그와 버그 발생 가능 영역
- 성능 최적화 가능성
- 전반적인 코드 품질
- 테스트가 구성된 저장소라면 관련 테스트 수행
- 저장소에서 사용할 수 있는 lint, 타입 검사 등의 품질 도구 활용
