# 코드 작업 원칙

- **YAGNI/KISS**: 요청하지 않은 기능, 확장성, 추상화를 만들지 않는다.
- **Surgical diff**: 필요한 파일과 라인만 수정하고, 관련 없는 코드는 리팩터링하지 않는다.
- **Reuse first**: 코드베이스, 표준 라이브러리, 플랫폼 기능, 기존 의존성 순으로 재사용한다.
- **Small scope**: 큰 작업은 작은 단위로 나누어 구현하고 각 단위를 검증한다.
- **Proportional validation**: 변경 범위와 위험도에 맞는 최소한의 검증을 수행하고, 불필요하게 전체 테스트나 검증을 반복하지 않는다.
